FOODIE HUB - FOOD ORDERING WEBSITE DEMO

Files:
- index.html
- css/style.css
- js/script.js

How to run:
1. Extract the ZIP file.
2. Open the foodie-hub folder.
3. Double-click index.html (or open it with Chrome/Edge).
4. Internet is needed for Bootstrap, Google Fonts and food photos.

Features:
- Responsive layout using Bootstrap 5
- Food menu with category filters and search
- Add items, change quantity and view cart total
- Demo checkout form with confirmation

Note:
This is a front-end student project. It does not have a server/database,
real delivery integration, login, or online payment. To make it a public
website, upload the folder to a hosting service such as GitHub Pages or
Netlify. Real orders require a secure backend and database.
