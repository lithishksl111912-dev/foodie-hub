The menu tries online food photography first. If the photo host cannot load,
it automatically uses included local SVG food artwork, avoiding broken images.
Features: responsive Bootstrap layout, search, category filters, cart,
quantity controls, total calculation and demo checkout.
This is a front-end student project; it does not process real orders or payments.
